Privacy Policy

Last updated: November 18, 2026

TDH YouTube is a private tool used only by its owner to manage the owner's own YouTube channels.

What data the tool uses

With the owner's permission (Google OAuth, YouTube scope), the tool reads the owner's channel ID and updates the "paid promotion" setting of videos the owner has uploaded. It does not read comments, subscribers, analytics, or any personal data of viewers.

Storage

The access token is stored only in the owner's own computer and private cloud environment. It is never sold, shared, or sent to third parties.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions: use the support email shown on the Google consent screen.
